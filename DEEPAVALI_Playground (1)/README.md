# DEEPAVALI — Interactive Festival Playground

A standalone HTML/CSS/JavaScript project.

## Run
Because the JavaScript uses ES modules, serve the folder through a local web server rather than opening index.html directly.

For example, from this folder:
- `python -m http.server 8000`
- Open `http://localhost:8000`

Three.js is loaded from jsDelivr, so the DiyaVerse needs an internet connection. The rest of the project is built with browser APIs.

## Included
- Premium responsive landing page and navigation
- Rangoli Studio: symmetry drawing, brushes, colour palette, undo, generate, save
- DiyaVerse: Three.js scene, click-to-place diyas, clear, save snapshot
- Light Painting: glowing brushes, burst, undo, clear, save
- Golden Hour: interactive evening slider and clickable homes
- My Creations: local gallery, download and delete
- Optional user-activated ambient audio
